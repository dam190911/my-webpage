# Daily Move 스마트폰 설치 안내

## 중요
스마트폰에 PWA로 설치하고 오프라인으로 사용하려면 HTTPS 주소로 먼저 배포해야 합니다. ZIP을 휴대폰에서 직접 열면 설치 기능과 서비스 워커가 작동하지 않습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. ZIP 압축을 풀고 안의 파일을 모두 저장소 최상위(root)에 업로드합니다.
3. 저장소 Settings → Pages로 이동합니다.
4. Deploy from a branch에서 `main`과 `/(root)`를 선택하고 저장합니다.
5. 생성된 `https://계정이름.github.io/저장소이름/` 주소를 스마트폰에서 엽니다.

## 홈 화면 설치
- Android Chrome: 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가
- iPhone Safari: 공유 버튼 → 홈 화면에 추가

처음에는 인터넷 연결 상태에서 앱을 한 번 열어 주세요. 그러면 앱 파일이 캐시되어 이후 오프라인에서도 열 수 있습니다.

## 기록 보관
운동 기록은 서버가 아닌 해당 기기의 브라우저 localStorage에 저장됩니다. 같은 기기·브라우저·배포 주소에서 사용해야 기록을 볼 수 있으며, 기기 간 자동 동기화는 되지 않습니다. 브라우저 데이터 삭제나 앱 제거 전 앱 안의 기록 백업 기능으로 JSON 파일을 보관하세요.
